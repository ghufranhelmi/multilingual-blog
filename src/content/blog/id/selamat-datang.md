# Selamat Datang! 👋

Ini adalah blog multibahasa yang dibangun dengan **Astro** dan **Decap CMS**, di-deploy di **Cloudflare Workers**.

## Apa yang bisa kamu lakukan

- Menulis postingan dalam 9 bahasa: English, 中文, Español, العربية, Bahasa Indonesia, Português, Français, 日本語, Русский
- Mengelola semua konten melalui panel admin Decap CMS di `/admin/`
- Layout otomatis right-to-left (RTL) untuk bahasa Arab
- Generasi situs statis yang cepat dengan Astro
- Hosting global gratis di Cloudflare

## Memulai

Kunjungi `/admin/` untuk mulai mengelola kontenmu. Masuk dengan akun GitHub kamu untuk mulai menulis.
