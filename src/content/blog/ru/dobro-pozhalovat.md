# Добро пожаловать! 👋

Это многоязычный блог, построенный на **Astro** и **Decap CMS**, развёрнутый на **Cloudflare Workers**.

## Что вы можете делать

- Писать статьи на 9 языках: English, 中文, Español, العربية, Bahasa Indonesia, Português, Français, 日本語, Русский
- Управлять всем контентом через панель администратора Decap CMS по адресу `/admin/`
- Автоматическое отображение справа налево (RTL) для арабского языка
- Быстрая генерация статического сайта с помощью Astro
- Бесплатный глобальный хостинг на Cloudflare

## Как начать

Перейдите на `/admin/`, чтобы начать управлять контентом. Войдите через свой аккаунт GitHub.
