# Добро пожаловать! 👋

Это многоязычный блог, созданный на **Astro** и **Decap CMS** и развернутый на **Cloudflare Workers**.

## Что вы можете делать

- Писать посты на 9 языках: английском, 中文, испанском, арабском, индонезийском, португальском, французском, японском и русском
- Управлять всем контентом через панель администратора Decap CMS по адресу `/admin/`
- Автоматическая верстка с направлением текста справа налево (RTL) для арабского языка
- Быстрая генерация статического сайта с помощью Astro
- Бесплатный глобальный хостинг на Cloudflare

## Начало работы

Посетите `/admin/`, чтобы начать управление контентом. Войдите в систему с помощью своей учетной записи GitHub, чтобы начать писать посты.
