# 欢迎！👋

这是一个使用 **Astro** 和 **Decap CMS** 构建的多语言博客，部署在 **Cloudflare Workers** 上。

## 你可以做什么

- 用9种语言写作：English, 中文, Español, العربية, Bahasa Indonesia, Português, Français, 日本語, Русский
- 通过 `/admin/` 的 Decap CMS 管理面板管理所有内容
- 阿拉伯语自动从右到左（RTL）排版
- 使用 Astro 快速生成静态网站
- 在 Cloudflare 上免费全球托管

## 开始使用

访问 `/admin/` 开始管理你的内容。使用 GitHub 账户登录即可开始撰写文章。
